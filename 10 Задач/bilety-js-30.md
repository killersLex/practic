# БИЛЕТ 7 Киноафиша

## ## Задача 1
 Афиша сначала показывает короткое описание фильма и кнопку «Подробнее». По нажатию заменяйте описание полным и подпись кнопки на «Свернуть». Повторное нажатие возвращает краткий вариант. Выбор между двумя текстами сделайте через if/else.

## Задача 2
 Дайте человеку ввести название кинотеатра и слоган. По кнопке обновляйте название шапки, слоган и подпись «Ваша афиша». Если слоган пустой, используйте «Хорошее кино рядом».

## Задача 3
 В списке предложите утренний, дневной и вечерний сеанс с разными временем и ценой. При выборе обновляйте время, цену и подпись сеанса. Флажок «Детский билет» уменьшает цену на заданную вами скидку и показывает статус скидки.

## Задача 4
 Дайте человеку ввести возраст посетителя и ограничение фильма. После нажатия кнопки выведите разрешение или отказ, выбранное ограничение, возраст и класс результата. Пустой возраст обрабатывать отдельно.

## Задача 5
 Сделайте раздел «Сеансы». Добавляйте название фильма, время и возрастное ограничение в массив. Проверяйте заполненность полей. Выведите афишу, число сеансов и сообщение о добавлении. После добавления очистите название и время. Кнопка очищает афишу.

## Задача 6
 Используйте цикл for: выведите сеансы, доступные посетителю указанного возраста. Покажите число доступных и недоступных сеансов; для пустого результата выведите сообщение.

## Задача 7
 Сделайте галерею из трёх локальных постеров с кнопками 1, 2, 3. По нажатию показывайте один постер, выделять одну цифру, меняйте название фильма и номер текущего постера. Используйте один обработчик для трёх кнопок.

## Задача 8
 Теперь добавьте к работе «Киноафиша» отдельный блок для общения с сервером. В нём нужны поля и четыре кнопки. Используйте API № 1.
 Кнопка GET получает одну запись и показывает её на странице. POST создаёт запись из полей. PUT отправляет все поля для замены записи. DELETE удаляет запись. После каждого действия человек должен видеть результат, название выполненного метода и HTTP-статус.
 Поля формы: title и body; userId отправляйте числом 1. Для POST и PUT укажите Content-Type: application/json, а тело подготовьте через JSON.stringify.
 POST сохраняет id созданной вами записи. PUT, PATCH и DELETE выполняйте только с этим id. Не изменяйте чужие записи. Пишите короткие именованные функции. Если DELETE вернул пустое тело, не вызывайте для него json().

## Задача 9
 Продолжите предыдущую задачу. Добавьте пятую кнопку - PATCH. PATCH меняет только title. После нажатия покажите ответ сервера и обновлённую карточку.
 Дайте человеку сохранить свою работу: полученную или созданную запись, текущие значения title и body и личную пометку. Сложите эти данные в один объект и сохраните в localStorage под ключом ticket07. Добавьте отдельную кнопку удаления этого сохранения.
 После обновления страницы поля и карточка должны восстановиться без нового запроса. Подпишите их «Сохранённые данные». Храните отдельно выбранный id для запросов и объект последнего ответа: у имитируемого POST эти id могут отличаться.
 На этом шаге достаточно короткого кода успешного выполнения. Помните: сохранённая в браузере копия не доказывает, что запись ещё существует на сервере.

## Задача 10
 Теперь доведите сетевой блок до состояния, в котором им удобно пользоваться. Кнопки запускают запросы, во время ввода меняется предпросмотр, а выбор статуса или оформления сразу обновляет карточку. Используйте обработчики click, input и change.
 До отправки проверьте пустые поля. Во время запроса покажите «Загрузка…» и не разрешайте отправить его повторно. Внутри try проверьте response.ok и структуру полученных данных. Для ошибок используйте catch, для возврата кнопок в рабочее состояние - finally: весь путь должен быть оформлен через try/catch/finally.
 Если запрос не удался, покажите понятное сообщение и оставьте введённый текст в полях. DELETE со статусом 204 не разбирайте через json(). Добавьте обработку ошибок записи, чтения и JSON.parse в localStorage.
 После успешного действия согласованно обновляйте карточку, статус, поля и доступность кнопок. Индивидуальное дополнение вашего билета: select выбирает оформление карточки; восстанавливается и оформление, и значение select.
